# Office 编辑器交互设计

> 目标：把 Office 插件从“能打开、能改一点”的页面，重建为与 GenOffice 同一交互水准的编辑器。
>
> 本文是**交互契约**，不是实现说明。它定义用户应该看到什么、能做什么、操作后发生什么、状态如何变化，以及验收标准。实现顺序见 §9。

## 0. 一页结论

| 格式 | 现状 | 目标 | 重写策略 |
| --- | --- | --- | --- |
| DOCX | GenOffice Docs 编辑器 fork，文本编辑/分页/Ribbon/审阅等能力基本完整 | 保留 GenOffice 级编辑体验，补齐 WorkStudio 壳层接入 | **保留编辑器内核，重写宿主桥接与页面外壳** |
| XLSX | 自绘只读网格 + 公式栏，只支持单格修改 | Excel/GenOffice 级网格：范围选择、单元格编辑、公式栏、剪贴板、撤销、结构调整、格式化 | **采用 Univer `preset-sheets-core`**（与 GenOffice Sheets 同源），重建页面外壳与写回 |
| PPTX | SVG 只读渲染 + 双击弹出文本框 | PowerPoint/GenOffice 级画布：选择、拖动/缩放/旋转、原位文本编辑、幻灯片管理、格式、撤销 | **重建交互层**；复用 `pptx-engine` / `pptx-render`，补 scene graph 与输入系统 |

当前最大问题不是“某个功能没做”，而是缺少一层**通用交互内核**：

- 没有统一的选择模型；
- 没有命令 / 事务 / 撤销栈；
- 没有指针命中测试、拖拽会话、双击判定；
- 没有键盘作用域与 IME 守卫；
- 没有剪贴板模型；
- 没有“对象进入编辑 → 提交 / 取消”的状态机；
- 没有页面外壳（Ribbon、右键菜单、对话框、状态栏）。

所以“连双击修改都没有实现”不是单点缺陷，而是上述内核缺失的直接表现。

## 1. 范围、术语与原则

### 1.1 范围

本文覆盖三类文档页面：

- DOCX：文字处理；
- XLSX：电子表格；
- PPTX：幻灯片。

覆盖的交互层：

- 指针、键盘、IME、剪贴板、拖拽；
- 选择、编辑、提交、取消；
- 撤销 / 重做；
- 视图缩放、滚动、焦点；
- 右键菜单、对话框、浮层、提示；
- 脏态、保存、外部变更；
- 与 WorkStudio 壳层的职责边界。

不覆盖：

- 文件格式解析与 ZIP/OOXML 编解码；
- 公式计算引擎内部；
- 字体排印、分页算法、富文本布局算法；
- AI、协作、宏、脚本；
- 服务器 / 云端能力。

### 1.2 术语

| 术语 | 含义 |
| --- | --- |
| 页面（page） | 插件提供的资源页，运行在 `app://page` 沙箱里 |
| 文档模型 | 编辑器持有的结构化数据，是保存的唯一来源 |
| 选择（selection） | 当前操作对象；可以是文本区间、单元格区域、图形集合 |
| 活动对象 | 选择中的主对象；键盘输入和格式化的默认目标 |
| 编辑会话 | 从进入编辑到提交/取消的临时状态 |
| 事务（transaction） | 一组原子修改，作为一个撤销单元 |
| 命令（command） | 可执行、可撤销的语义操作 |
| 页面外壳 | Ribbon / 工具栏 / 状态栏 / 对话框 / 右键菜单 |
| 壳层（shell） | WorkStudio 主窗口：标签、主题、保存、系统菜单 |

### 1.3 交互原则

1. **直接操作**：点击对象就选中，双击可编辑对象就进入编辑，拖动就移动；不需要先切换模式。
2. **可发现**：任何可编辑对象都有可见的进入路径（双击、F2、Ribbon、右键菜单）。
3. **可撤销**：所有改变文档模型的操作都必须进入撤销栈；选择、滚动、缩放不进。
4. **键盘等价**：指针能完成的核心操作，键盘也能完成；反之亦然。
5. **平台一致**：macOS 用 ⌘，Windows/Linux 用 Ctrl；系统快捷键（⌘W、⌘Q、⌘M）不被页面吞掉。
6. **状态可见**：选中、编辑中、脏、保存中、保存失败、外部变更都要有明确反馈。
7. **不丢数据**：提交前可取消；保存失败保留内存稿；外部变更不静默覆盖。
8. **输入不打架**：对话框、菜单、编辑会话、画布快捷键各有作用域；IME 组合期间不触发命令。

## 2. 现状基线与差距

### 2.1 现状基线

#### DOCX

- 页面层来自 GenOffice Docs 的 fork；
- 已有：ProseMirror 文本编辑、分页视图、Ribbon、样式、查找替换、表格、图片、页眉页脚、批注、修订、打印/导出等；
- 已移除：GenOffice 的 AI 面板、选区 AI、AI 审阅等；
- 已适配：页面会话字节、`ura.page.saveBytes`、主题、脏态；
- 主要缺口：WorkStudio 系统菜单 / 打开 / 另存为 / 导出 / 打印 / 最近文件等宿主动作还没有完全接回壳层。

#### XLSX

当前实现实际上是一个**带公式栏的只读表格查看器**：

- 单工作表视图 + 工作表标签；
- 最多显示 200 行 × 40 列；
- 单击选中单元格，方向键移动；
- 双击只把焦点移到顶部公式栏，没有单元格内编辑；
- 没有范围选择、行列选择、多选；
- 没有复制/剪切/粘贴/填充；
- 没有撤销/重做；
- 没有格式化、插入/删除行列、调整行高列宽、冻结、合并、查找；
- 没有右键菜单；
- 保存只提交修改过的单元格。

#### PPTX

当前实现实际上是一个**带幻灯片导航的只读渲染器**：

- SVG 渲染幻灯片；
- 缩略图 / 上一页 / 下一页；
- 双击文本弹出居中的模态文本框；
- 保存通过 `savePptx` 回写整份文件；
- 没有画布选择、拖动、缩放、旋转；
- 没有多选、框选、组合、层级；
- 没有幻灯片新增/删除/复制/排序；
- 没有文本原位编辑（模态框不是原位编辑）；
- 没有格式化、插入、撤销、剪贴板、右键菜单、放映。

### 2.2 与 GenOffice 的差距

| 能力 | DOCX | XLSX | PPTX |
| --- | --- | --- | --- |
| 对象选择 | 文本区间 / 表格 / 图片等 | 仅单格 | 无 |
| 双击进入编辑 | 原生文本 | 仅聚焦公式栏 | 模态框 |
| 键盘导航 | 完整 | 仅方向键 | 仅翻页 |
| 撤销 / 重做 | 完整 | 无 | 无 |
| 剪贴板 | 完整 | 无 | 无 |
| 格式化 | 完整 | 无 | 无 |
| 结构操作 | 完整 | 无 | 无 |
| 右键菜单 | 完整 | 无 | 无 |
| 缩放 | 完整 | 无 | 固定比例 |
| 页面外壳 | Ribbon | 极简工具栏 | 极简工具栏 |
| 保存 | 字节整篇 | 单格补丁 | 文本补丁 |

差距的本质：

- XLSX 缺的是 **Excel 的交互内核**（选择、编辑、公式栏、剪贴板、结构、历史）；
- PPTX 缺的是 **画布的交互内核**（scene graph、命中选择、变换、文本编辑、历史）；
- 两者都缺 **页面外壳**（Ribbon、对话框、右键菜单、状态栏）。

### 2.3 重写边界

| 保留 | 重写 |
| --- | --- |
| URA 页面会话、`saveBytes`、主题、脏态 | 页面外壳（Ribbon / 工具栏 / 状态栏） |
| DOCX GenOffice Docs 编辑器 fork | DOCX 宿主桥接与系统命令接入 |
| `pptx-engine` 解析、`pptx-render` 绘制列表 | PPTX 画布交互层（选择/变换/文本编辑） |
| XLSX OOXML 解析、`patchWorkbook` 写回 | XLSX 网格交互层（选择/编辑/结构/历史） |
| 现有 codec / presenter / sidecar 契约 | 页面内部状态管理与输入路由 |

> “从头实现”指**页面交互层与产品外壳**，不是重写文件格式引擎。格式引擎已经存在，重写它们不会缩短与 GenOffice 的交互差距。

### 2.4 GenOffice 交互基线（分析依据）

#### Docs

| 维度 | 基线 |
| --- | --- |
| 编辑内核 | ProseMirror / Tiptap，原生选区、IME、剪贴板、撤销 |
| 快捷键 | 70+ 条，分 file / edit / text / para / insert / review / view 七组 |
| 页面外壳 | Ribbon 九个标签页、样式库、标尺、导航窗格、多页缩略图 |
| 审阅 | 批注、修订、比较、接受/拒绝、字数统计 |
| 文件 | 打开/保存/另存为/打印/PDF/HTML/Markdown |
| 交互特征 | 双击选词、三击段落、格式刷、查找替换、页眉页脚双击进入 |

#### Sheets

| 维度 | 基线 |
| --- | --- |
| 编辑内核 | Univer（`@univerjs/core` + sheets / formula / find-replace / filter / sort / table / conditional-formatting / data-validation / note / drawing presets） |
| 快捷键 | Univer 原生 + Excel 标准补充（Home/End/PgUp/PgDn、Ctrl+Space、插入删除、工作表切换） |
| 选择 | 单元格/区域/行/列/全表；活动单元格；多区域；冻结窗格 |
| 编辑 | 单元格内编辑器、公式栏、名称框、公式引用拾取 |
| 结构 | 行列插入删除/隐藏/调整大小、合并、冻结、工作表管理 |
| 格式 | 字体/数字格式/边框/填充/对齐/条件格式/单元格样式 |
| 数据 | 排序、筛选、表、透视、数据验证、图表、批注、保护 |
| 交互特征 | `grid / sheet / idle / formulaBar` 四类快捷键门控；模态框打开时全局键不生效；公式栏与网格共享选择 |

#### Slides

| 维度 | 基线 |
| --- | --- |
| 渲染 | Konva 画布 + `@genoffice/pptx-render` 绘制列表 |
| 选择 | 单选/多选/框选/Tab 循环/进入组；选择框 + 8 个缩放手柄 + 旋转手柄 |
| 文本编辑 | DOM contentEditable 覆盖层，原位编辑 run 级富文本；双击进入、Esc/F2 提交退出 |
| 直接输入 | 选中文本图形后输入字符 = 替换全文；Enter = 末尾编辑；F2 = 全选 |
| 变换 | 拖动/缩放/旋转/微移/吸附/对齐/分布/层级/组合 |
| 幻灯片 | 新建/复制/删除/排序/节/版式 |
| 放映 | F5 / Shift+F5、演讲者视图、动画 |
| 交互特征 | 双击动作有优先级：可编辑文本 → 进入组 → 表格单元格 → 媒体播放 → 上下文标签；编辑框内点击文本行放光标、点击框空白拖动图形 |

#### 可直接借鉴的规则

1. **双击优先级**：可编辑文本 > 组 > 表格单元格 > 媒体 > 上下文标签。不要所有对象都打开同一个对话框。
2. **Esc/F2 提交而非取消**：PPTX 文本编辑退出时保留修改；取消只用于明确的“撤销本次编辑”。
3. **直接输入替换**：选中文本图形后输入字符直接替换全文，这是 PowerPoint 用户的基础预期。
4. **编辑框内命中分区**：文本行放光标，框内空白拖动图形；避免“点哪里都不能拖”。
5. **快捷键门控**：按 `grid / sheet / idle / formulaBar` 区分作用域；模态框打开时画布键全部失效。
6. **撤销路由**：文本编辑中 ⌘Z 交给原生文本撤销；退出编辑后 ⌘Z 才撤销文档操作。
7. **遮罩优先级**：菜单/对话框/裁剪/绘制模式打开时，Esc 先关闭最内层，不穿透到画布。
8. **状态栏与选择联动**：选中变化立即更新公式栏/属性面板/状态栏，而不是等下一次点击。

## 3. 通用交互内核

### 3.1 页面生命周期

```
loading ──► ready ──► editing ──► committing ──► ready
              │           │
              │           └── cancel ──► ready
              ├── saving ──► ready / error
              ├── stale ──► reload / overwrite
              └── error
```

| 状态 | 含义 | 页面表现 |
| --- | --- | --- |
| loading | 解析文档 / 首屏渲染 | 启动占位，禁止交互 |
| ready | 可交互，无编辑会话 | 选择可见，菜单可用 |
| editing | 文本/单元格编辑中 | 编辑器获得焦点，部分全局快捷键让位 |
| committing | 提交编辑 / 保存前收敛 | 短暂锁定，防重复提交 |
| saving | 保存请求进行中 | 保存按钮禁用，状态提示 |
| stale | 外部变更或版本过旧 | 顶部提示“重新加载 / 继续覆盖” |
| error | 打开/保存/渲染失败 | 错误页 + 重试 |

**脏态**与生命周期正交：`dirty = 模型版本 != 已保存版本`。选择、滚动、缩放、折叠面板不产生脏态。

### 3.2 输入路由

所有输入先进入统一路由，再分发给当前作用域：

```
pointerdown/move/up ─┐
keydown/keyup       ─┼─► InputRouter ─► 作用域栈 ─► 当前处理器
composition         ─┤
contextmenu         ─┤
paste/copy/cut      ─┘
```

作用域栈从内到外：

| 作用域 | 例子 | 规则 |
| --- | --- | --- |
| modal | 对话框、确认框 | 拦截 Tab / Enter / Esc；焦点陷阱 |
| text-editor | 单元格编辑器、PPTX 文本框 | 文本键、IME、撤销交给原生编辑 |
| inline-overlay | 右键菜单、下拉、颜色面板 | Esc 关闭；点击外部关闭 |
| grid / canvas | 表格、画布 | 选择、方向键、Delete、F2 |
| page | 页面级快捷键 | Ctrl/Cmd+S、查找、缩放 |
| shell | WorkStudio 壳层 | 标签、主题、系统菜单 |

规则：

- **IME 守卫**：`event.isComposing || event.keyCode === 229` 时，不处理 Enter / Escape / 方向键 / 字符命令。
- **可编辑目标守卫**：焦点在 input/textarea/contentEditable 时，全局字母快捷键让位给文本输入。
- **模态守卫**：对话框打开时，画布/网格快捷键不生效。
- **默认行为**：页面自己处理的键必须 `preventDefault()`；不处理的键不要拦截。
- **平台修饰键**：`mod = metaKey || ctrlKey`；macOS 单独处理 ⌘W / ⌘Q / ⌘M / ⌘H 等系统键。

### 3.3 双击与拖拽判定

| 判定 | 规则 |
| --- | --- |
| 单击 | pointerdown 与 pointerup 在同一对象、移动 < 4px、间隔 < 400ms |
| 双击 | 两次 pointerdown 间隔 < 400ms、位移 < 4px、同一命中对象 |
| 拖拽启动 | 按下后移动 > 3px 才进入拖拽，避免手抖误拖 |
| 右键 | 先选中命中的对象（若未选中），再打开自定义菜单；阻止原生菜单 |
| 框选 | 空白处拖拽 > 3px 进入框选；Shift 追加；Esc 取消 |
| 自动滚动 | 拖拽/框选到达视口边缘时按距离加速滚动 |

### 3.4 选择模型

所有格式共享同一条规则：**选择是操作的输入，不是文档修改**。

| 格式 | 选择类型 | 主对象 |
| --- | --- | --- |
| DOCX | 文本区间 / 节点选择 | ProseMirror selection |
| XLSX | 单元格区域 / 行 / 列 / 全表 | 活动单元格 |
| PPTX | 图形集合 / 文本区间 / 表格单元格 | primary element |

选择变化必须：

- 更新页面外壳（公式栏、Ribbon 状态、属性面板）；
- 触发可视选中态；
- 不进入撤销栈；
- 不产生脏态；
- 失焦时保留（窗口失焦可以弱化显示，但不丢失）。

### 3.5 编辑会话状态机

```
idle ──进入编辑──► editing ──提交──► committing ──► idle
  ▲                    │
  └──────取消──────────┘
```

| 阶段 | 规则 |
| --- | --- |
| 进入 | 双击可编辑对象、F2、直接输入、Ribbon 命令、粘贴 |
| 编辑中 | 原生文本输入、IME、选区、光标、上下文菜单；全局字母键让位 |
| 提交 | Enter / Tab / 点击外部 / 失焦 / 切换对象；写入事务 |
| 取消 | Esc / 撤销编辑 / 切换文档；不写入历史 |
| 空提交 | 内容未变化时不产生事务，不标脏 |
| 多行 | XLSX 用 Alt+Enter；PPTX 用 Enter；DOCX 原生换行 |

**一次编辑会话 = 一个撤销单元**。连续键入在提交时合并；不能每个字符一个撤销步。

### 3.6 命令、事务与历史

```
Command ──► Transaction ──► Model mutation ──► Render ──► History
```

| 概念 | 说明 |
| --- | --- |
| Command | 语义操作：`setCell`、`moveElements`、`setText`、`insertRows` |
| Transaction | 一个原子修改集合；可包含多个 Command |
| History | 线性撤销栈 + 重做栈；事务入栈 |
| Save point | 保存成功时记录当前历史位置 |
| Dirty | 当前历史位置 != save point，或模型版本变化 |
| Coalesce | 文本输入、连续拖动按时间/对象合并 |

不进入历史：

- 选择、滚动、缩放、展开/折叠面板；
- 打开对话框、切换 Ribbon 标签；
- 保存、导出；
- 主题切换。

必须进入历史：

- 单元格值/公式、格式、结构变更；
- 文本/图形增删改、移动、缩放、旋转、层级；
- 幻灯片增删改序；
- 粘贴、剪切、填充、删除。

### 3.7 剪贴板

统一抽象：

```ts
interface ClipboardPayload {
  type: 'text' | 'cells' | 'elements' | 'slide'
  text?: string
  html?: string
  data: unknown
}
```

| 场景 | 行为 |
| --- | --- |
| 页面内复制 | 写入内部剪贴板，同时写系统剪贴板（text/html） |
| 从系统粘贴 | 优先内部格式；否则解析 TSV/HTML/纯文本 |
| 图片 | `image/png`；PPTX 可粘贴为图片元素 |
| 剪切 | 复制 + 删除；删除进入历史 |
| 粘贴 | 目标选择处插入；不覆盖隐藏内容 |
| 粘贴选项 | P1：保留源格式 / 仅值 / 仅格式 |
| 权限失败 | 提示“无法访问剪贴板”，不崩溃 |

### 3.8 保存与外部变更

| 事件 | 行为 |
| --- | --- |
| 模型变化 | `dirty = true`，壳层显示未保存 |
| Ctrl/Cmd+S | 页面提交当前编辑 → `ura.page.saveBytes` |
| 保存成功 | 更新基线版本，`dirty = false`，清除“保存失败” |
| 保存失败 | 保留内存稿，提示错误；按钮可重试 |
| 外部变更 | `ura.onChange` 收到版本变化；非脏时自动重载，脏时提示 |
| 关闭标签 | 壳层询问；页面先 flush 编辑会话；未保存由壳层决定 |
| 版本冲突 | WorkStudio 当前为最后写入胜出；页面必须提示“已覆盖外部修改”或由壳层提供冲突策略 |

保存是**整篇字节提交**；页面不直接写文件，不持有路径。XLSX/PPTX 在页面内维护增量修改，保存时生成完整字节。

### 3.9 页面外壳

| 区域 | 归属 | 说明 |
| --- | --- | --- |
| 标签、主题、窗口菜单 | WorkStudio 壳层 | 页面不复制 |
| Ribbon / 工具栏 | 页面 | 按格式提供；与选择状态联动 |
| 公式栏 / 名称框 | XLSX 页面 | 与网格共享选择状态 |

| Toast | 页面 | 保存、复制、错误反馈；不阻塞 |

| 触发 | 行为 |
| --- | --- |
| 双击单元格 | 进入单元格内编辑；光标放在点击位置；双击文字选中词 |
| F2 | 进入编辑，光标在末尾 |
| 直接输入可打印字符 | 进入编辑，并用输入字符替换原内容 |
| 单击公式栏 | 进入编辑；网格选区保持不变 |
| 粘贴 | 进入编辑或直接写入选区（按内容类型） |
| Enter | 提交，活动单元格下移 |
| Shift+Enter | 提交，上移 |
| Tab | 提交，右移 |
| Shift+Tab | 提交，左移 |
| 点击其他单元格 | 提交当前编辑，再选中目标 |
| 失焦 | 提交 |
| Esc | 取消，不写入模型 |
| Alt+Enter | 单元格内换行 |

单元格编辑器要求：

- 是一个覆盖在单元格上的原生 input / textarea；
- 与单元格同字体、同对齐、同 padding；
- 进入时全选或按点击位置放光标；
- 支持文本选区、复制/粘贴、撤销（文本级）；
- 提交时解析为：空、数字、布尔、文本、公式、错误；
- 编辑期间公式栏同步显示；
- 提交后刷新显示值、格式、错误标记。

### 4.5 公式与计算

| 阶段 | 规则 |
| --- | --- |
| 读取 | 文件缓存值作为初始值；Univer 公式引擎负责页面内重算 |
| 编辑 | 以 `=` 开头进入公式模式；公式栏显示源码 |
| 提交 | Univer 实时计算结果；保存时写回 `<f>`，缓存值写回在 ChangePlan 接入后补齐 |
| 重算 | 页面内由 Univer 公式引擎完成；保存不依赖 Excel 重算 |
| 引用拾取 | P1：编辑公式时点击单元格插入引用 |
| 函数提示 | P2：自动补全、参数提示、函数对话框 |

**当前写回边界**：公式与值已经可保存；缓存值（`<v>`）的写回随后由 ChangePlan / `xlsx-gateway` 补齐，确保不打开 Excel 也能读到结果。

### 4.8 格式化

P0 工具栏/ Ribbon：

- 字体、字号；
- 加粗、斜体、下划线；

- 格式刷；

- 行列隐藏与分组。

### 4.9 右键菜单

| 命中对象 | 菜单项（P0） |
| --- | --- |
| 单元格/区域 | 剪切、复制、粘贴、清除内容、插入、删除、合并、行高列宽、设置单元格格式 |

| 操作 | 是否进历史 |
| --- | --- |

| 工作表切换 | 否 |

### 4.11 保存

- 修改单元格/格式/结构后标脏；

## 5. PPTX 交互规格

### 5.1 模型与坐标

```
Deck
├─ slides: Slide[]
│  ├─ size: { width, height }
│  ├─ elements: Element[]
│  └─ background / notes / layout
├─ currentSlide
├─ selection: { ids, primaryId, editingId, groupId }
├─ viewport: { scale, offsetX, offsetY }
└─ history
```

| 对象 | 字段 |
| --- | --- |
| Element | `id` / `type` / `box` / `rotation` / `z` / `text` / `style` / `media` |
| ElementType | `text` / `shape` / `picture` / `table` / `chart` / `group` / `connector` / `media` |
| Box | `x` / `y` / `w` / `h` |
| Selection | `selectedIds` / `primaryId` / `editingId` / `groupId` |

坐标规则：

- 所有模型坐标使用幻灯片坐标；
- 指针坐标先经视口变换（缩放/滚动）再命中测试；
- 选择框、手柄、参考线用屏幕坐标渲染，避免缩放后线宽变化；
- 旋转元素的命中测试先逆旋转到元素局部坐标。

### 5.2 视图布局

```
┌ 幻灯片缩略图栏 ┬ 画布（当前幻灯片） ┬ 属性面板（可选） ┐
│ 1              │  ┌──────────────┐  │ 文本 / 形状 / 图片  │
│ 2              │  │   幻灯片      │  │                    │
│ 3              │  └──────────────┘  │                    │
├ 状态栏：页码 · 缩放 · 选中对象                          ┘
└ Ribbon：开始 / 插入 / 绘图 / 设计 / 切换 / 动画 / 放映 / 视图
```

| 区域 | 要求 |
| --- | --- |
| 缩略图栏 | 当前页高亮；点击切换；多选；拖拽排序；右键菜单 |
| 画布 | 适配宽度/页面；缩放；滚动；选择框/手柄/参考线 |
| 属性面板 | 选择变化时更新；格式修改实时生效 |
| 状态栏 | 当前页/总页数；缩放；选中数量 |
| Ribbon | 按选择类型启用/禁用命令 |

### 5.3 选择

| 操作 | 结果 |
| --- | --- |
| 单击图形 | 选中该图形 |
| Shift/Ctrl/Cmd+单击 | 加入/移出多选 |
| 空白处拖拽 | 框选 |
| 单击空白 | 取消选择 |
| Tab / Shift+Tab | 按 z 序循环选择 |
| Esc | 取消选择；若在组内则退出组 |
| 双击文本 | 进入文本编辑 |
| 双击组 | 进入组内选择 |
| 双击表格单元格 | 进入单元格编辑 |
| 双击图片/媒体 | 打开预览/播放（按类型） |
| 右键 | 若未选中则先选中，再打开菜单 |

选择框：

- 单选：元素边界框 + 8 个缩放手柄 + 1 个旋转手柄；
- 多选：整体边界框 + 各元素细框；
- 选中文本编辑中：文本编辑框，不显示缩放手柄；
- 选择框颜色/线宽在深浅背景下都可见。

### 5.4 变换

| 操作 | 规则 |
| --- | --- |
| 拖动元素 | 移动；3px 阈值；吸附参考线/网格（P1） |
| 拖动缩放手柄 | 缩放；Shift 保持比例；Alt 从中心缩放（P1） |
| 拖动旋转手柄 | 旋转；Shift 15° 步进；显示角度 |
| 方向键 | 微移 1px；Shift+方向键 10px |
| 拖动多选 | 整体移动 |
| 拖动选择框边缘 | 移动（非编辑文本时） |
| 编辑文本时拖框 | 提交文本并移动图形 |

变换期间：

- 实时更新幽灵框/元素位置；
- 松开时提交一个事务；
- 连续拖动合并为一个撤销步；
- 超出画布不裁剪（保持可恢复）；
- 显示坐标/尺寸提示（P1）。

### 5.5 文本原位编辑

**这是当前差距最大的交互之一。**

| 触发 | 行为 |
| --- | --- |
| 双击可编辑文本 | 在图形位置叠加 contentEditable；光标落在点击位置；双击词选中词 |
| 选中文本图形后直接输入字符 | 进入编辑，并用该字符替换全部文本（PowerPoint 行为） |
| 选中文本图形后 Enter | 进入编辑，光标在末尾 |
| F2 | 进入编辑，全选文本 |
| 表格单元格双击 | 进入单元格编辑；Tab/Shift+Tab 切换单元格 |
| Esc | 提交并退出编辑，回到图形选择 |
| 点击画布空白 | 提交并退出编辑 |
| 点击其他图形 | 提交当前编辑，选中新图形 |
| Enter | 换行（段落） |
| Ctrl/Cmd+Enter | 下一个占位符（P1，Windows 行为） |
| IME 组合中 | 不提交、不退出、不触发快捷键 |

编辑框要求：

- 与画布文本同字体、字号、行高、内边距、对齐；
- 覆盖在图形边界上，不改变画布布局；
- 支持文本选区、复制/粘贴、撤销（文本级）；
- 支持富文本 run（粗体/斜体/下划线/颜色/链接）；
- 支持项目符号与多段落；
- 提交时提取段落/run 结构，写入模型；
- 文本为空时保留空文本框（不要自动删除）；
- 编辑中隐藏画布上该图形的文本，避免重影。

退出规则：

- 点击文本编辑框外的**文本行矩形**：提交；

## 7. 技术架构

### 7.1 分层

```
┌─────────────────────────────────────────────────────┐
│ WorkStudio 壳层：标签 / 主题 / 保存 / 系统菜单          │
├─────────────────────────────────────────────────────┤
│ 页面外壳：Ribbon / 状态栏 / 对话框 / 右键菜单 / Toast   │
├─────────────────────────────────────────────────────┤
│ 交互内核：InputRouter / Selection / History / Clipboard│
├─────────────────────────────────────────────────────┤
│ 格式控制器：GridController / CanvasController / DocCtrl│
├─────────────────────────────────────────────────────┤
│ 格式引擎：XLSX model / PPTX scene / ProseMirror        │
└─────────────────────────────────────────────────────┘
```

### 7.2 共享交互内核

建议新增 workspace 包（名称暂定 `@workstudio/editor-core`）：

| 模块 | 职责 |
| --- | --- |
| `InputRouter` | 指针、键盘、IME、右键、剪贴板事件分发 |
| `Keymap` | 作用域、平台修饰键、快捷键表 |
| `Selection` | 选择状态与变更通知 |
| `History` | 事务、撤销/重做、保存点、dirty |
| `Clipboard` | 内部/系统剪贴板、MIME、粘贴选项 |
| `Overlay` | 对话框栈、焦点陷阱、Esc 栈 |
| `Persistence` | 页面会话、保存队列、外部变更 |
| `Theme` | 页面主题同步 |
| `Pointer` | 双击/拖拽/框选/自动滚动 |

格式控制器实现统一接口：

```ts
interface EditorController<State> {
  readonly state: State
  mount(host: EditorHost): void
  dispatch(command: Command): void
  undo(): void
  redo(): void
  flush(): Promise<void>
  destroy(): void
}

interface EditorHost {
  page: PageSession
  theme: 'light' | 'dark'
  setDirty(dirty: boolean): void
  toast(message: string, kind?: 'info' | 'error'): void
  openDialog(dialog: DialogRequest): Promise<unknown>
}
```

### 7.3 XLSX 实现方案

| 方案 | 优点 | 缺点 | 建议 |

若选 A，页面代码只负责：

## 10. 已定方案

> 原则：**和 GenOffice 使用同样的方案**。不另造交互内核，页面层只做 WorkStudio 适配。

### 基准优先级

| 层级 | 基准 | 说明 |
| --- | --- | --- |
| 产品交互 | **GenOffice** | Ribbon 布局、快捷键、右键菜单、对话框、选择行为、状态栏，以 GenOffice 对应 App 为准 |
| 网格/画布引擎 | **Univer / Konva** | GenOffice 本身使用的底层引擎；提供选择、编辑、命中、渲染等能力 |
| 文件写回 | **codec + xlsx-gateway / pptx-engine** | WorkStudio 的 URA presenter 负责字节提交；结构/格式写回按 GenOffice 的 ChangePlan 方案 |

冲突时的规则：

1. **GenOffice 行为优先于 Univer 默认值**：Univer 自带的工具栏、菜单、快捷键只是底层能力；GenOffice 已经定制过的部分（如 `toolbar:false` + 自定义 Ribbon、Excel 快捷键门控、单元格右键菜单、状态栏）以 GenOffice 为准。
2. **WorkStudio 壳层优先于 GenOffice 宿主**：标签、主题、保存、系统菜单归 WorkStudio；GenOffice 的 Electron main/preload、Home、AI 面板不进入插件。
3. **文件正确性优先于交互便利**：页面不能产生无法写回的结构/格式修改；在 ChangePlan 接入前，未覆盖的命令必须拦截。

### 具体方案

| 决策 | 已定方案 | 实现含义 |
| --- | --- | --- |
| XLSX 网格 | **Univer `preset-sheets-core`** | 与 GenOffice Sheets 同一套选择、单元格编辑、公式栏、剪贴板、撤销 |
| XLSX 公式 | **Univer 公式引擎** | 页面内实时计算；保存时写回公式与缓存值 |
| PPTX 渲染 | **Konva + `pptx-render`** | 与 GenOffice Slides 同一套画布/命中/变换方案 |
| PPTX 文本编辑 | **DOM contentEditable overlay** | 与 GenOffice 的 `TextEditOverlay` 同构 |
| 页面外壳 | **React** | Ribbon、对话框、属性面板、上下文菜单统一组件化 |
| 保存冲突 | 最后写入胜出 | 先沿用 WorkStudio 页面会话；页面提示 stale，后续补版本校验 |
| 自动保存 | 壳层决定 | 页面只提供 flush / save |
| P0 范围 | 核心交互 | 先完成选择、双击编辑、键盘、剪贴板、撤销、保存；格式/结构写回随后接入 |

GenOffice 组件级复用地图见 [`genoffice-reuse-map.md`](./genoffice-reuse-map.md)。

**当前落地顺序**：
